# 🎓 SmartTube-AI — YouTube AI Study Tool

> Turn any YouTube video into a complete study kit using AI — instantly!

🔗 **Live Demo:** [smart-tube.streamlit.app](https://smart-tube.streamlit.app)

---

## ✨ What is SmartTube-AI?

SmartTube-AI is an AI-powered web application that analyzes any YouTube video and automatically generates:
- 📋 Summarized notes
- 🧠 Interactive quizzes
- 📒 Structured study notes
- 💡 Real-world applications
- 🎯 Flashcards for revision
- 💬 A chatbot to ask questions about the video

No need to watch long videos — just paste the link and study smart! 🚀

---

## 🖥️ Features

| Feature | Description |
|---|---|
| 📋 **Summary** | AI-written 8-point summary of the video topic |
| 🧠 **Quiz** | 10 MCQ questions with score, timer & improvement areas |
| 📒 **Notes** | Sectioned, formatted study notes with PDF download |
| 💡 **Applications** | Real-world use cases of the topic |
| 🎯 **Flashcards** | Click-to-reveal revision cards |
| 💬 **Chat** | Ask anything about the video topic |
| 🌐 **Language** | English, Hindi, Marathi support |
| 🎯 **Difficulty** | Easy, Medium, Hard quiz levels |
| ⏱️ **Timer** | 15-minute countdown for quiz |
| 📄 **Export** | Download quiz & notes as PDF / Google Forms |
| 🖼️ **Preview** | Video thumbnail & title shown before analysis |
